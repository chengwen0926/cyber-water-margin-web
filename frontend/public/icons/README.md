# Desktop pixel icons

64 × 64 SVG icons drawn on an integer grid with crisp edges, stepped silhouettes, slate-blue shadows, warm paper and mint highlights. Transparent backgrounds keep assets usable in desktop and window surfaces.

- `readme.svg`: folded paper
- `email.svg`: envelope and outgoing arrow
- `archives.svg`: layered folder and mint clasp
- `medical.svg`: tiled medical cross and terminal
- `chat.svg`: overlapping speech bubbles
- `trash.svg`: mesh wastebasket and discarded paper

`apple.svg` remains the menu bar asset. Application icons are mapped in `WindowChrome.tsx`.
