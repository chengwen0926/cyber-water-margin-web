# 赛博水浒入职日

本地单机 HR 审查模拟游戏。前端 Next.js（像素风 Macintosh 桌面），后端 FastAPI，数据以本地 JSON 文件持久化。详见 `specs/specs.md` 与 `specs/design.md`。

## 开发环境

一键启动（同时拉起前后端，Ctrl+C 一并停止）：

```bash
uv run python launch.py
```

或分别在两个终端启动：

```bash
# 终端 1：后端 (FastAPI, http://localhost:8000)
cd backend
uv run uvicorn main:app --reload --port 8000

# 终端 2：前端 (Next.js, http://localhost:3000)
cd frontend
npm run dev
```

前端通过 `NEXT_PUBLIC_API_BASE_URL` 环境变量指向后端地址，默认 `http://localhost:8000`（可复制 `frontend/.env.local.example` 为 `frontend/.env.local` 自定义）。

## 后端测试

```bash
cd backend
uv run pytest
```

## 游戏流程

1. 登录（装饰性，无真实鉴权）
2. 点击菜单栏「进入下一天」生成当日候选人队列
3. 在「邮箱」双击简历附件预览，或将附件拖入「档案」建立候选人档案
4. 将医疗原件、对话记录等拖入对应档案，核对待核实项与矛盾，再提交通过/拒绝判定
5. 在「医疗库」查看体检原件、与简历比对
6. 在「聊天」与领导/候选人对话，处理领导下达的特殊密令
7. 点击「结束今天」触发当日结算与惩罚判定

## 阅读状态

邮箱、档案、医疗库和聊天的侧边栏均提供「全部 / 未读 / 已读」筛选，列表仅显示匹配内容；切换筛选会清空当前详情。打开未读内容后，该项移入已读列表，详情保留供继续操作，不会自动打开下一项。列表同时显示「已读 / 未读」状态。只有内容加载成功并显示在当前活动窗口中，才会标为已读；下载附件、审查判定与阅读状态互相独立。阅读记录保存在 `save.json` 的 `read_receipts` 中，刷新页面或重启服务后保留。

聊天按联系人和消息版本记录阅读状态，新对话节点、新一天或领导新来电会重新显示未读；共用脚本的候选人不会共用阅读记录。桌面聊天图标显示未读会话数量。旧存档没有阅读历史，首次启用时现有内容按未读处理。

## 聊天与视频面谈

聊天窗口采用深色三栏布局：左侧导航、中间联系人目录、右侧聊天记录。支持搜索联系人和全部 / 未读 / 已读筛选。聊天沿用游戏剧情选项，选择回复后点击「发送」（或在发送按钮上按 Enter），服务端确认后保存双方消息；记录自动滚动并可在刷新后恢复。密令和线索仍由剧情节点触发。

点击联系人右上角「视频聊天」，会打开可拖动、缩放的独立会议窗口；会议包含角色主画面、我方小窗、右侧聊天和底部控制栏。支持宫格 / 演讲者视图、聊天栏收起 / 展开及结束通话。会议与普通聊天共用已保存的对话进度。结束或关闭会议会释放窗口计时器，保留聊天记录。

游戏事件触发来电时，桌面弹出接听 / 拒绝提示，接听后直接进入来电联系人的会议。拒绝仅关闭来电提示，不将消息标为已读；后续可从聊天目录继续查看。现有剧情触发领导来电，事件可附带 `contact_id` 与 `caller_name` 指定其他联系人（未提供时兼容领导来电）。

这是单机游戏内的虚拟面谈，目前未接入角色视频素材、真实摄像头、麦克风采集或多人音视频传输。角色画面显示头像 / 姓名占位，静音和画面按钮控制虚拟参会状态。窄窗口下聊天目录与会话分屏显示，会议画面与聊天上下排列。

## 桌面文件与档案工作流

桌面空白区域右键可新建文件夹，文件右键可重命名或移到废纸篓；废纸篓支持恢复。邮件附件采用文件图标，双击或按 Enter 查看内容，可拖到桌面、文件夹或档案窗口。文件夹支持嵌套，禁止移动到自身或子文件夹。显示设置提供游戏屏幕亮度、图标大小和动效开关，文件及设置随存档保存。

简历导入档案时会提取游戏材料中的结构化字段。补充医疗原件后重新评估字段，将其区分为待核实、一致和矛盾；对话与历史资料保留来源，作为背景补充，不自动消除事实矛盾。重复导入同一材料不会重复计数。此流程处理游戏内附件，尚不解析玩家电脑上的任意 PDF 或 Word 文件。

集团资料库提供人物、事件和新闻背景条目。搜索入口已预留，检索逻辑暂未实现。简历预览与档案详情显示候选人联系方式，可直接添加好友，也可在聊天窗口点击「添加好友」输入该地址；添加好友与建立档案相互独立。完成至少一次剧情回复后，可将对话记录拖入对应档案。

窗口打开、附件预览及归档具有加载提示，拖拽时显示文件影像与目标高亮；显示设置可关闭动效。

视频会议右侧聊天支持输入文字，Enter 发送、Shift+Enter 换行。快捷剧情回复会填入输入框，发送后推进剧情；自由留言会保存并获得基于现有剧情的规则回复，目前未接入生成式 AI。发送失败保留草稿，重新进入会话可恢复双方记录。
